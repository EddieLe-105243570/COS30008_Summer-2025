### Exercise 1: Smart Pointers

**Objective:** Understand and implement smart pointers in C++.

**Instructions:**

1. Create a class named `Resource` that has a constructor and a destructor that print messages when they are called.
2. Use `std::unique_ptr` to manage an instance of `Resource` in the main function.
3. Modify the code to demonstrate the automatic memory management provided by `std::unique_ptr`.

#### Example Code:

```cpp
#include <iostream>
#include <memory>

class Resource {
public:
    Resource() { std::cout << "Resource acquired." << std::endl; }
    ~Resource() { std::cout << "Resource released." << std::endl; }
};

int main() {
    // Using unique_ptr
    std::unique_ptr<Resource> resPtr = std::make_unique<Resource>();
    // std::unique_ptr<Resource> copyPtr = resPtr; // ❌ Error: cannot copy
    std::unique_ptr<Resource> movedPtr = std::move(resPtr); // ✅ Ownership transferred

    // Using shared_ptr
    std::shared_ptr<Resource> sharedResPtr = std::make_shared<Resource>();
    std::shared_ptr<Resource> sharedCopy = sharedResPtr; // ✅ Copying increases ref count

    std::cout << "Shared count: " << sharedResPtr.use_count() << std::endl;

    return 0;
}

```

#### Questions for Exploration:

- What happens if you try to copy `resPtr`? Why is this not allowed?

<!-- std::unique_ptr cannot be copied because it has exclusive ownership. Copying would violate the ownership model. Only move semantics are allowed to transfer ownership. -->

- Modify the code to use `std::shared_ptr` instead of `std::unique_ptr`. What changes do you need to make?

<!-- Replace std::unique_ptr with std::shared_ptr. Shared ownership allows multiple pointers to manage the same resource. -->

- How does using smart pointers prevent memory leaks compared to raw pointers?

<!-- Smart pointers automatically delete the memory they manage when they go out of scope, ensuring resources are freed. With raw pointers, you must manually delete memory, which can easily be forgotten and cause leaks. -->

### Exercise 2: Cloning and Object Duplication

**Objective:** Implement cloning functionality in a class using a virtual clone method.

**Instructions:**

1. Define a class named `Shape` with a virtual method `clone()` that returns a pointer to a new object of the same type.
2. Create derived classes, such as `Circle` and `Square`, that implement the `clone()` method.
3. In the main function, create an instance of `Circle`, clone it, and display information about both objects.

#### Example Code:

```cpp
#include <iostream>
#include <memory>

class Shape {
public:
    virtual std::unique_ptr<Shape> clone() const = 0;
    virtual void draw() const = 0;
    virtual ~Shape() {}
};

class Circle : public Shape {
public:
    std::unique_ptr<Shape> clone() const override {
        return std::make_unique<Circle>(*this);
    }
    void draw() const override {
        std::cout << "Drawing Circle" << std::endl;
    }
};

class Square : public Shape {
public:
    std::unique_ptr<Shape> clone() const override {
        return std::make_unique<Square>(*this);
    }
    void draw() const override {
        std::cout << "Drawing Square" << std::endl;
    }
};

class Triangle : public Shape {
public:
    std::unique_ptr<Shape> clone() const override {
        return std::make_unique<Triangle>(*this);
    }
    void draw() const override {
        std::cout << "Drawing Triangle" << std::endl;
    }
};

int main() {
    std::unique_ptr<Shape> circle = std::make_unique<Circle>();
    circle->draw();

    std::unique_ptr<Shape> clonedCircle = circle->clone();
    clonedCircle->draw();

    std::unique_ptr<Shape> triangle = std::make_unique<Triangle>();
    triangle->draw();

    std::unique_ptr<Shape> clonedTriangle = triangle->clone();
    clonedTriangle->draw();

    return 0;
}

```

#### Questions for Exploration:

- How does the cloning mechanism ensure that each shape has its own independent state?

<!-- The clone() method returns a deep copy, creating a new object with its own memory. -->

- What would happen if you did not use smart pointers for managing shapes? Discuss potential memory management issues.

<!-- Without smart pointers, you need manual delete, increasing the risk of memory leaks or dangling pointers. -->

- Modify the code to add another derived class, such as `Triangle`, and implement its cloning behavior.

### Exercise 3: Circular Data Structures

**Objective:** Implement a circular linked list and demonstrate proper memory management.

**Instructions:**

1. Create a class named `CircularLinkedList` that contains nodes with integer data.
2. Implement methods to add nodes, display the list, and properly free memory when the list is destroyed.
3. Demonstrate adding several nodes and displaying them in a circular manner.

#### Example Code:

```cpp
#include <iostream>

class Node {
public:
    int data;
    Node* next;

    Node(int value) : data(value), next(nullptr) {}
};

class CircularLinkedList {
private:
    Node* head;

public:
    CircularLinkedList() : head(nullptr) {}

    void add(int value) {
        Node* newNode = new Node(value);
        if (!head) {
            head = newNode;
            newNode->next = head;
        } else {
            Node* temp = head;
            while (temp->next != head) {
                temp = temp->next;
            }
            temp->next = newNode;
            newNode->next = head;
        }
    }

    void display() const {
        if (!head) return;
        Node* temp = head;
        do {
            std::cout << temp->data << " ";
            temp = temp->next;
        } while (temp != head);
        std::cout << std::endl;
    }

    void remove(int value) {
        if (!head) return;

        Node* current = head;
        Node* prev = nullptr;

        do {
            if (current->data == value) {
                if (current == head) {
                    Node* temp = head;
                    while (temp->next != head)
                        temp = temp->next;
                    if (head->next == head) {
                        delete head;
                        head = nullptr;
                    } else {
                        temp->next = head->next;
                        Node* toDelete = head;
                        head = head->next;
                        delete toDelete;
                    }
                } else {
                    prev->next = current->next;
                    delete current;
                }
                return;
            }
            prev = current;
            current = current->next;
        } while (current != head);
    }

    ~CircularLinkedList() {
        if (!head) return;
        Node* current = head->next;
        while (current != head) {
            Node* nextNode = current->next;
            delete current;
            current = nextNode;
        }
        delete head;
    }
};

int main() {
    CircularLinkedList cll;
    cll.add(1);
    cll.add(2);
    cll.add(3);
    cll.add(4);

    std::cout << "Circular Linked List before removal: ";
    cll.display();

    cll.remove(3);
    std::cout << "After removing 3: ";
    cll.display();

    cll.remove(1);
    std::cout << "After removing 1: ";
    cll.display();

    return 0;
}

```

#### Questions for Exploration:

- How does the destructor ensure that all nodes are properly deleted without causing memory leaks?

<!-- It iterates and deletes each node, freeing heap memory before program termination. -->

- What challenges might arise when using circular references with smart pointers? Discuss how you could address these challenges.

<!-- Using std::shared_ptr for circular references leads to memory leaks due to reference cycles. Solutions include using std::weak_ptr for back-pointers. -->

- Modify the circular linked list implementation to include a method for removing nodes from the list.
